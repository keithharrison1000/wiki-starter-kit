# About this vault

`general` holds cross-cutting notes: shared conventions, templates, and
anything that doesn't belong to one specific hobby or work knowledge base.
Each other knowledge base lives in its own vault (its own folder, its own
Obsidian vault, registered in `vaults.toml` at the repo root) — see the
root `README.md` for how to add one.

# Conventions

Frontmatter, the `type` vocabulary, and the note-filing workflow are
documented in [Conventions](conventions.md) — the canonical copy; every
other vault carries its own copy of the same file, since vaults can't
link to each other. See [templates/note.md](templates/note.md) for the
starter frontmatter to begin a new note from.
